Alexa+ is a brilliant talker, and the conversation stays hers. Intent Lock is a tiny, stubborn referee that stands between her and the catalogs, and checks every song, cable and grocery order against the real thing before it plays, ships, or gets ordered.

2:05 · Tested like an enemy

We didn’t grade our own homework. We hired the enemy.

The host brain in production is Alexa+. So we tested against hosts that behave worse: three Gemini personas, careful, careless and sloppy, extracting structure from 55 everyday utterances, mistakes and all. Then we published every failure and fixed them one by one.

Final acceptance gate on the finished tree, 22 Oct 2026 · methodology and the full gate table: docs/TESTING.md in the repo

How the 100% was computed

The gate replayed the 36 wrong-locks against the fixed kernel: 36 fixed, 0 still wrong, 0 changed. The 125 previously-safe runs were carried, not re-fed. Both percentages use the same denominator: 161 completed runs. Four runs never reached a verdict (1 host extraction error, 3 kernel errors), and nothing played in them.

The confession

28 of the 36 wrong locks came from clean host extractions. The hosts did their job and the referee still crowned the wrong row, so the referee was the weak link. The crowning layer was rebuilt, and the same attacks were replayed. Final gate on the finished tree: kernel suite 10/10 · saboteur battery 10/10 · demo beats 5/5 · rig left pristine.

What it still cannot do

  • A free-form “no added sugar” grocery ask can end in an honest no_lock. The grocery text grounding tops out below the never-guess floor, so the kernel refuses rather than guesses.
  • One accent-garbled ask locked a cover rendition, because the cover’s own title carries the film name and the original carries it in the album name. The card showed the artist it locked, in the open.
  • Preview playback depends on the browser’s decode path. The lock itself never does.

FL-17 · MCP Apps

Task
Render catalog artwork and preview audio inside the MCP App.
Expected
CSP failures would show an error somewhere.
Actual
MCP Apps CSP is deny-by-default. Undeclared domains fail silently; the card simply renders broken.
Severity
Medium
Workaround
Declared resource and connect domains in the app metadata; verified media loads.
Suggestion
Hosts should surface CSP-blocked resources in a debug channel. Silent media failure cost hours.

FL-18 · Spec change

Task
Choose the tie-breaking mechanism for the 2025-11-25 spec.
Expected
MCP sampling would be a stable foundation.
Actual
Sampling is deprecated (SEP-2577). Building on it would have dated the entry on arrival.
Severity
Medium
Workaround
The server returns tie_choice; the host re-calls with a pin; the server re-verifies. Two ordinary tool calls.
Suggestion
Deprecations belong in the tool-authoring guides, not only in the changelog.

FL-19 · Catalogs

Task
Fetch a spelling-mangled title, “Sayaraa”, from catalog APIs.
Expected
The catalogs would fuzzy-match a one-glide misspelling.
Actual
They are spelling-based. “Sayaraa” returns a Sahara-only pool; the correct song is absent, not merely misranked.
Severity
High
Workaround
Deterministic respelling variants race alongside the heard form, and an audited snapshot joins every race.
Suggestion
Catalog search APIs should offer a phonetic, sounds-like match mode.

FL-20 · Safety

Task
Prove a hosted LLM extraction could not resurrect a server-banned version.
Expected
Server vetoes would be absolute.
Actual
A host hint could reopen a hard trap. The unverified boundary existed inside our own engine.
Severity
High
Workaround
The exception now comes only from the user’s own words, and never when the class is vetoed.
Suggestion
Any host field that can weaken a server safety verdict is a vulnerability class in MCP reviews.

FL-24 · Host context

Task
Evaluate a spoken time rule, “after 10 PM, Saiyaara means the lofi version”, against the correct clock.
Expected
The server could use its own clock.
Actual
Server-local time is the wrong clock for a user’s rule, and a time argument would be spoofable host input.
Severity
Medium
Workaround
Host time travels only as per-request _meta.host_time. The server validates its shape and labels the clock source on the result.
Suggestion
Standardize a per-request host-context channel in MCP: clock, locale, device class.
