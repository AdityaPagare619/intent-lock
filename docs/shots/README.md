# Screenshots

Real captures of the running demo stage — no mockups, no renders. If a
screenshot in this folder cannot be reproduced by booting the demo and
clicking the same path, it does not belong here.

| File | What it shows |
| --- | --- |
| `main-interface.png` | The Alexa+ simulator stage — the main interface: conversation on the left, the live Intent Lock wire and Trust Card on the right. *(Hero shot; linked from the root README.)* |
| `tie-card.png` | A `tie_choice` Trust Card: two recordings of one name, told apart by year, film and version chips — the user taps to pin; the server re-verifies. |
| `trust-card.png` | A `locked` Trust Card: the winning recording, its lock score against the floor, and the transparent elimination list under it. |
| `video-poster.jpg` | Poster frame from the demo video. |

`main-interface.png`, `tie-card.png` and `trust-card.png` are captured
from the final verified build at submission time.
